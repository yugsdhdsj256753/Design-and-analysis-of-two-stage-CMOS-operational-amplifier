# Design-and-analysis-of-two-stage-CMOS-operational-amplifier
## Statement
The project involved transistor-level design, biasing, transistor sizing, and DC, AC, transient, and pole-zero analyses. The designed op-amp achieved approximately 68 dB DC gain, 16.20 MHz gain crossover frequency, and 9.38 kHz 3-dB bandwidth.
